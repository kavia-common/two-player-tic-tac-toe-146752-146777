# Two-Player Tic Tac Toe (Ocean Professional Theme)

A lightweight React implementation of a two-player Tic Tac Toe game with an ocean-inspired professional theme.

## Features

- Local two-player mode (X and O), turn-by-turn play
- Win and draw detection with clear, friendly status messages
- Polished UI: subtle gradients, rounded corners, soft shadows, smooth transitions
- Theme colors:
  - Primary: `#2563EB` (blue)
  - Secondary: `#F59E0B` (amber)
  - Error: `#EF4444`
  - Background: `#f9fafb`
  - Surface: `#ffffff`
  - Text: `#111827`

## Scripts

- `npm start` – Run in development mode at http://localhost:3000
- `npm test` – Run tests
- `npm run build` – Build production bundle

## Play

1. Click any square to place the current player's mark.
2. Players alternate automatically.
3. When a player wins, the winning line highlights amber.
4. Use “Restart Game” to reset anytime.

## Files of interest

- `src/App.js` – Game logic and components
- `src/App.css` – Ocean Professional themed styles
- `src/App.test.js` – Basic UI and interaction tests

Enjoy the game!
